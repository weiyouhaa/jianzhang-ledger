# 简账 · 现代 iOS 记账 App

一款纯本地、无网络请求的 SwiftUI 记账应用，支持 **快捷指令识图记账** 和 **App 密码 / 面容 ID 锁**。

- 最低系统：iOS 17
- 技术栈：SwiftUI · SwiftData · Swift Charts · App Intents · Vision（设备端 OCR）· LocalAuthentication
- App 名称：**简账**（`CFBundleDisplayName`），Bundle ID：`com.fve.ledger`（可改，见下文）
- 产物：GitHub Actions 在 macOS 上编译出 **未签名** 的 `JianZhang-unsigned.ipa`，自行签名安装

---

## 功能

### 记账
- 收入 / 支出记录的新增、编辑、删除（左滑删除 / 编辑）
- 字段：金额、分类、备注、商户、账户（可选：现金 / 支付宝 / 微信 / 银行卡…）、时间
- 编辑页可「从支付截图识别填写」（相册选图，本机 OCR）
- 自定义分类：名称、SF Symbols 图标、颜色（预设色 + 取色器），拖动排序；内置 12 个支出分类和 6 个收入分类
- 首页：月度结余 / 收入 / 支出汇总卡片、预算进度，按天分组的明细（每天显示当日收支），左右切换月份
- 统计：月度 / 年度切换；分类饼图（环形图）+ 分类排行（可点进看明细）；每日 / 每月趋势柱状图；年度收支对比图；日均支出、笔数
- 预算：每月总预算（可选结余结转到下月）、年度总预算、**分类月预算**；首页、统计页、「预算」页显示进度，超 80% 变橙、超支变红；可开启预算提醒（见下文）
- 搜索 / 筛选：关键词（备注、商户、分类、账户、金额）、收支类型、分类、日期范围、金额区间
- CSV 导出（UTF-8 BOM，Excel 直接打开不乱码），通过系统分享面板保存到「文件」或发送
- 外观：跟随系统 / 浅色 / 深色；货币符号可选

### 智能记账（设置 › 智能记账）

**分类记忆 / 记账规则**
- 记账或修改记录时，如果填了商户，会记住「商户 → 分类 + 账户」（商户名去掉分店括号、「有限公司」等后缀后比较，支持模糊包含，如「星巴克咖啡（国贸店）」与「星巴克」）。可在「记账规则」中关闭自动学习。
- 之后 **识图记账（快捷指令）、编辑页识图、账单导入、记一笔时输入商户** 都会优先按规则选择分类和账户，规则没命中时才用关键词猜测。
- 「记账规则」页可查看命中次数、编辑、停用、删除（左滑），并可添加 **关键词规则**（如「高速 → 交通 · 招行信用卡」「医保 → 医疗」「工资 → 收入·工资」），商户或备注包含关键词即套用，长关键词优先。
- 记一笔时选择分类会自动带出该分类上次使用的账户。

**支付宝 / 微信账单导入**
- 支持支付宝「交易明细」CSV（GBK / GB18030 编码，前面带说明行）、微信支付账单 XLSX（新版）或 CSV（旧版）。XLSX 由内置的 ZIP + Deflate 解压和 XML 解析读取，没有第三方依赖；万一读不了，用 Numbers / Excel 另存为 CSV 再导入。
- 获取账单：支付宝 › 我的 › 账单 › ··· › 开具交易流水证明 › 用于个人对账；微信 › 我 › 服务 › 钱包 › 账单 › 常见问题 › 下载账单 › 用于个人对账。账单以加密压缩包发到邮箱，解压（密码在支付宝 / 微信消息中）后存到「文件」，在 设置 › 导入支付宝 / 微信账单 中选择。
- 处理规则：交易关闭 / 支付失败、已全额退款的交易跳过；部分退款按净额记账，对应的退款行自动跳过；其他退款记为收入「退款」（可关闭）；「不计收支」（信用卡还款、余额宝 / 零钱通转入、充值提现）匹配到两个不同账户时记为转账，否则跳过。
- 付款方式按名称 / 卡号尾号匹配账户（花呗、余额宝、零钱、招商银行信用卡(1024)…），分类依次按记账规则 → 平台交易分类 → 关键词。
- 导入前预览：新交易 / 重复 / 跳过的数量与合计，逐笔勾选，点开可修改类型、分类、账户（可「同商户全部应用并记住」）。
- 去重：交易订单号保存在记录中，同一订单不会重复导入；与已有记录时间相差 3 分钟内且金额相同的标记为「疑似重复」，默认不导入。
- 每次导入记为一个批次，可在「导入记录」中整批撤销。

**周期账单与提醒**
- 房租、会员、工资、信用卡还款（转账）等：每天 / 每周（星期几）/ 每月（几号或最后一天，31 号在小月自动取月末）/ 每年，可设「每 N 个周期」、截止日期或次数。
- 「自动记账」：打开 App 或回到前台时补记到今天为止的各期，同一期不会重复生成（记录上带有周期标记，多设备同步产生的重复会自动清理）。
- 「仅提醒」：到期发本地通知，通知上可直接点「已付」（需解锁）记一笔，或点「记一笔」打开预填好的记账页。可设提前几天、几点提醒；待发通知总数限制在 50 个以内（iOS 上限 64）。
- 「周期账单」页显示每项的下次日期、本月预计支出 / 收入；记录编辑页可「设为周期账单」（这一笔即第一期）。
- 只有在打开某个提醒开关时才会请求通知权限。

**预算提醒**
- 开启后，在记账、导入账单、快捷指令记账、周期自动记账之后检查总预算 / 分类预算 / 年度预算，用到设定比例（默认 80%）和超支时各提醒一次。

### 资产负债

- 底部第三个标签「资产」：顶部卡片显示 **净资产 / 总资产 / 总负债**（及负债率），右上角 / 卡片上的眼睛按钮可一键隐藏金额。
- 账户按类型分组：现金、储蓄卡、支付宝、微信、投资理财、借出 / 应收、其他资产；负债有信用卡、花呗 / 白条、借入 / 贷款、其他负债。
- 余额 = 初始余额 + 收入 − 支出 ± 转账（转出方另扣手续费）+ 余额校准。负债账户余额为负数，界面上显示为「欠款」。
- 信用卡 / 花呗显示已用 / 可用额度，设置账单日、还款日后显示「N 天后还款」。
- 账户详情：余额（欠款）走势图、该账户的全部收支与转账；可直接「记一笔」「转账 / 还款」「余额校准」（输入真实余额，差额记为一笔不计入统计的校准记录）。
- 净资产趋势图（最近 12 个月月末）。新建 / 编辑 / 归档 / 删除账户，「排序与归档」中拖动排序。
- 记账页新增「转账」类型（转出 → 转入账户、手续费），信用卡还款即从储蓄卡转账到信用卡。**转账与余额校准不计入收支统计和预算。**
- 升级说明：首次启动新版本时，会根据旧记录里填写的账户文字自动创建账户（类型按名称猜测，可再编辑）并关联记录，旧的文字字段仍然保留。
- **公积金与社保**：账户类型新增住房公积金、医保个人账户、养老保险个人账户、个人养老金、企业年金（资产页合并为「公积金与社保」分组），负债新增房贷（商贷 / 公积金贷款）、车贷（可设每月还款日）。
  - 养老保险个人账户、个人养老金、企业年金默认 **不计入净资产**（可在账户中打开）；有这类账户时净资产卡片额外显示不含它们的「可支配资产」。
  - 新记录类型「缴存」：只增加账户余额，不计入收入、统计和预算。账户编辑页可设「每月缴存」金额和日期，自动生成一个缴存类周期账单（从下一个缴存日开始）。
  - 公积金「提取」即从公积金账户转账到银行卡。
- **长按账户**：资产页长按账户行弹出预览和菜单「修改余额 / 记一笔（缴存）/ 转账 / 编辑账户」。「修改余额」直接输入实际余额（负债输入欠款），显示差额，可选记为「余额校准」（不计收支，默认）或一笔收入 / 支出。
- 快捷指令「记一笔」可选「账户」参数；「识图记账」会根据截图中的付款方式（支付宝 / 微信 / 花呗 / 信用卡 / 银行卡尾号）自动匹配账户。
- 备份文件升级为 version 2，包含账户与转账；仍可导入旧版（version 1）备份，导入后按账户文字自动关联。CSV 增加「账户 / 转入账户 / 手续费」列。
- 备份 **version 3** 再增加：记账规则、周期账单、导入批次、分类预算、分类上次账户、订单号 / 周期标记，以及年度预算、结转等设置。v1 / v2 备份仍可导入。

### 应用锁
- 可选 4 / 5 / 6 位数字密码，**加盐 + 多轮 SHA-256 哈希后存入钥匙串**（`WhenUnlockedThisDeviceOnly`，不同步 iCloud），明文不落盘
- 可选面容 ID / 触控 ID 解锁（需先设置密码；开启时会先验证一次）
- 启动时、以及从后台返回时显示锁屏；可设置「离开后多久需要解锁」（立即 / 30 秒 / 1 / 5 / 15 分钟 / 1 小时）
- 连续输错 5 次后逐级锁定（30 秒起，翻倍递增）
- 修改密码、关闭密码都必须先输入当前密码
- 多任务界面隐私遮罩：App 进入非活跃状态时自动遮挡内容（可关闭）
- 锁屏与遮罩使用独立的高层级窗口，即使当时打开着编辑页等弹窗也能完全遮住

### iCloud 与备份
设置 › **iCloud 与备份** 提供两层方案：

**① 备份到 iCloud 云盘（任何签名方式都可用，推荐）**
- 「导出备份到文件…」：生成带版本号的备份 `简账备份-yyyyMMdd-HHmmss.jzbackup`（加密，默认）或 `.json`（明文），包含全部记录、分类和预算 / 货币 / 主题 / 默认账户等设置（**不含 App 密码和面容 ID 设置**）。在系统存储面板里选择「iCloud 云盘」即可存到云端。
- 「从备份恢复…」：从「文件」选择备份 → 预览（备份时间、来源设备、记录 / 分类数量、时间范围、收支合计）→ 选择：
  - **合并**：按记录 UUID 去重，已存在的跳过；同类型同名分类自动对应，不会重复；
  - **替换全部数据**：二次确认后删除当前所有记录和分类再导入，同时恢复预算等设置。
  - 若设置了 App 密码，恢复前必须输入密码。
- **自动备份**（可选），两种方式：
  - **每次打开/关闭时更新**（默认）：App 启动 / 回到前台、切到后台时（申请后台时间写完）更新**同一个文件** `简账自动备份.jzbackup`（关闭加密时为 `.json`）。先写同目录临时文件再整体替换（iCloud 容器内用 `NSFileCoordinator` 协调），写到一半崩溃也不会损坏原备份；按内容指纹（SHA-256）判断，数据没变就不重写。另可保留**每日快照**（默认开启，保留最近 7 天，可选 3 / 7 / 14 / 30），防止误删数据后滚动文件被覆盖。
  - **定期保留多份**：每天 / 每 3 天 / 每周，回到 App 时到期自动备份，只保留最近 5 / 10 / 20 / 30 份。
  - 显示上次更新时间和位置。签名带 iCloud 权限时写入 iCloud 容器，出现在「文件 › iCloud 云盘 › 简账」；
  - 否则写入 App 的「文稿」目录（已开启 `UIFileSharingEnabled` / `LSSupportsOpeningDocumentsInPlace`），在「文件 › 我的 iPhone › 简账」中可见，可以手动复制或移到 iCloud 云盘。

**备份加密（默认开启）**
- 导出备份时默认「加密备份」：设置备份密码（至少 6 位，两次输入，显示强度），生成 `.jzbackup` 文件。格式：文件头 `JZBK` + 格式版本 + KDF 参数（PBKDF2-HMAC-SHA256，迭代次数按本机速度校准到约 0.5 秒、不少于 60 万次，写在文件头里）+ 16 字节随机 salt + 12 字节 nonce；内容是原有的 v3 备份 JSON（zlib 压缩后）用 **AES-256-GCM**（CryptoKit）加密，整个文件头作为附加认证数据，改动任何一个字节都会解密失败。加密 / 解密在后台线程进行并显示进度。
- ⚠️ **备份密码无法找回**：简账不上传、不保存密码的任何副本（除非你选择保存在本机钥匙串）。忘记密码，这份备份就**永远无法恢复**，请另外妥善记录。
- 可选「在本机钥匙串记住密码」（仅此设备、不随 iCloud 钥匙串同步）：自动备份每次都用同一个密码加密，不会重复询问，只有你主动修改才会更换。查看 / 修改 / 移除已保存的密码，以及恢复时「使用已保存的密码」，都需要先验证 App 密码或面容 ID（未设 App 密码时用设备密码）。开启加密且开启自动备份但没有保存密码时，会提示设置；在设置之前自动备份暂停，**不会改写明文**。
- 仍可关闭加密导出**明文 JSON**（会显示明文警告）。恢复时按文件头自动识别：加密备份先输入密码（密码错误或文件被修改会提示，不会崩溃），再显示原有的预览；旧版 v1–v3 明文 JSON 备份照常导入。
- 「导出 CSV」前会提示 CSV 是明文文件。
- 测试：`Tools/BackupCryptoCheck` 在 CI 的 macOS 上运行（CryptoKit / CommonCrypto 在 Linux 不可用），覆盖加解密往返、错误密码、逐字节篡改（文件头 / salt / nonce / 密文 / 标签）、截断、未来版本，以及 `Tests/Fixtures/backup` 中 v1 / v3 明文备份解析。

**② iCloud 自动同步（CloudKit，需付费开发者账号）**
- 打开「iCloud 同步」开关后，**完全退出并重新打开 App** 生效。数据存入 iCloud 私有数据库 `iCloud.<Bundle ID>`（默认 `iCloud.com.fve.ledger`），在登录同一 Apple ID 的设备间同步。
- 开启时会检测：设备是否登录 iCloud（`ubiquityIdentityToken`）、当前签名能否访问 iCloud 容器。检测不通过不会开启；如果启动时 CloudKit 容器创建失败，会自动回退到本机存储，不会闪退，状态栏会说明原因。
- **必须使用付费 Apple 开发者账号签名**，并在开发者后台为 App ID 开启 iCloud（CloudKit）能力、创建上述容器，签名时带上 `Config/Ledger.entitlements` 中的权限（构建产物中也附带了这个文件）。免费 Apple ID、爱思助手、Sideloadly、AltStore 的签名通常会去掉 iCloud 权限，此时请用方案 ①。
- 本地和 iCloud 模式使用同一个数据库文件，开关切换不会丢失本机数据；首次开启会把现有数据上传到 iCloud。多台设备各自生成的默认分类会按「类型 + 名称」自动合并。建议开启前先导出一次备份。

### 防窥模式
- 设置 › 安全与隐私 › **防窥模式**：需先开启 App 密码锁，再设置与真实密码**不同**的防窥密码（同样加盐哈希存钥匙串）。
- 锁屏输入**防窥密码** → 进入独立的防窥账本（`LedgerDecoy.store`，永不走 CloudKit）。首次自动填入一套普通的小额流水；可在真实模式下「编辑防窥数据」或「重置为预设数据」。
- 锁屏使用**面容 ID / 触控 ID** 或**真实密码** → 始终进入真实账本。
- **数据与偏好完全隔离**：SwiftData 容器分开；预算 / 年度预算 / 结转 / 预算提醒、默认账户、货币符号、分类记忆开关、隐藏金额等偏好走独立 UserDefaults suite（`com.fve.ledger.decoyprefs`），真实数字不会出现在防窥界面。
- 进入防窥时撤掉真实账本的待发与已送达本地通知；回到真实账本后再按真实库重排周期提醒。多任务隐私遮罩仍可用。无 Spotlight / Widget 索引。
- 防窥界面与真账看起来一样，不出现「防窥」字样。设置里隐藏真实备份 / iCloud / 导出入口，自动备份不会运行，也不会覆盖 `简账自动备份.jzbackup`。修改 App 密码在防窥模式下会提示「暂时无法修改」。
- 快捷指令（识图记账等）**始终写入真实账本**（对话片段也只读真实预算）。

### 快捷指令 / Siri（App Intents）
| 操作 | 说明 |
| --- | --- |
| **识图记账** | 传入图片（截屏 / 照片），本机 OCR 识别金额、商户、时间并猜测分类。**审核方式**：「弹窗审核」（默认，不打开 App，在弹窗中增删改后保存）或「直接保存」。可选参数：指定分类、收支类型、账户、备注。返回保存的金额合计。 |

Siri 短语示例：「用简账识图记账」「简账记一笔」「简账本月收支」。

识图规则（`Ledger/OCR/ReceiptParser.swift`）：
- 金额：识别 `¥ / ￥ / RMB / 人民币 / 元`、正负号、千分位；优先「实付款 / 实付 / 支付金额 / 付款金额 / 合计 / 总计 / 交易金额」等关键词后（或下一行）的数字；降低「优惠 / 抵扣 / 余额 / 运费 / 原价」等附近数字的权重；自动排除日期、时间、订单号、卡号尾号、百分比、数量
- **一图多笔**：按日期标题（`昨天 下午3:25`、`星期四 晚上9:05`、`10月17日`、`2026-10-17`…）、多条银行短信、账单列表行（`滴滴出行 -23.50`）以及多个大字金额（利用 Vision 文字框高度）把截图拆成多笔，快捷指令一次全部记入；App 内识别到多笔时让你选择填写哪一笔
- **去重**：同金额、同商户、时间相差 2 分钟内已有记录的跳过（重复识别同一张截图不会重复记账），并在结果里列出跳过的笔数
- 收支：**默认支出**。带 `-`、或出现「支付成功 / 使用…支付 / 对方已收款 / 扣款 / 消费 / 实付」记支出；只有「收款到账 / 收款成功 / 已到账 / 退款成功 / 已存入零钱 / 收入 / 工资」或 `+` 号等明确信号才记收入（「对方已收款」是对方收到钱 = 你的支出）
- 商户：「商户全称 / 收款方 / 交易对方 / 付款方 / 商品说明…」后的文字，否则取金额上方的卡片标题行；会去掉头像图标被误识别出的单个字母 / 符号（如「C 阿芳」→「阿芳」）
- 时间：`2026-10-17 08:45`、`2026年10月16日 19:20`、`10月12日 下午3:20`、`昨天 下午3:25`、`前天 凌晨12:30`、`星期四 晚上9:05`、`10-16 15:00` 等，按 24 小时制换算；没有就用当前时间
- 账户：`使用零钱支付` → 微信；`交通银行信用卡 (7316)` → 名称 / 备注含 7316 或「交通银行 / 交行」的信用卡，否则第一张信用卡，再否则默认账户（不会自动新建账户）
- 分类：按关键词猜测（美团 / 星巴克 → 餐饮，滴滴 / 加油 / 12306 → 交通，淘宝 / 京东 / 超市 → 购物，电影 / 游戏 → 娱乐，电费 / 水费 / 燃气 → 生活缴费，高速 / ETC / 通行费 → 交通……），找不到则归入「其他」

解析器测试：`Tools/ParserCheck`（纯文本样例，Linux / macOS 均可运行）；`Tools/VisionCheck` 在 CI 的 macOS 上对 `Tests/Fixtures/*.png` 真实截图跑 Vision OCR 并打印识别结果。

## 编译（GitHub Actions）

仓库自带 `.github/workflows/build.yml`：

1. 把本目录推送到你自己的 GitHub 仓库（私有仓库也可以）。
2. 每次 push 都会在 `macos-15` 上：选择最新稳定版 Xcode → `brew install xcodegen` → `xcodegen generate` → `xcodebuild archive`（关闭签名）→ 打包 `Payload/Ledger.app` 为 `JianZhang-unsigned.ipa`。
3. 在 Actions 运行页面底部 **Artifacts** 下载 `JianZhang-unsigned-ipa`（解压后得到 ipa）。
4. 推送 `v*` 标签（如 `git tag v1.0.0 && git push --tags`）时会自动创建 GitHub Release 并附上 ipa。
5. 也可以在 Actions 页面手动运行（workflow_dispatch），并填写自定义 Bundle ID。

> Xcode 工程由 `project.yml` 生成，不提交 `.xcodeproj`。本地有 Mac 时：`brew install xcodegen && xcodegen generate && open Ledger.xcodeproj`。

修改 Bundle ID / 版本号：编辑 `project.yml` 中的 `PRODUCT_BUNDLE_IDENTIFIER`、`MARKETING_VERSION`、`CURRENT_PROJECT_VERSION`。

## 签名与安装

ipa 未签名，任选一种方式安装：

- **爱思助手**：工具箱 → IPA 签名 → 导入 ipa → 使用 Apple ID 签名（免费账号 7 天有效）→ 安装到设备。
- **Sideloadly**（Windows / macOS）：连接 iPhone，拖入 ipa，填写 Apple ID，点 Start。免费账号需每 7 天重签。
- **AltStore / SideStore**：在 AltStore 中「My Apps → ＋」选择 ipa，AltStore 会自动续签。
- **自有证书**（个人 / 企业开发者账号）：用 `zsign`、`ios-app-signer` 或 Xcode 重签：
  ```bash
  zsign -k dev.p12 -p 证书密码 -m dev.mobileprovision -o JianZhang-signed.ipa JianZhang-unsigned.ipa
  ```
  描述文件的 App ID 需与 Bundle ID 一致（或使用通配符）。

安装后首次打开如提示「未受信任的开发者」：设置 › 通用 › VPN 与设备管理 › 信任对应开发者。iOS 16+ 还需在 设置 › 隐私与安全性 中打开 **开发者模式**。

> 免费 Apple ID 签名的应用，部分系统功能（如 Siri 短语）可能需要打开一次 App 后才会出现在「快捷指令」中。重签时如果 Bundle ID 变了，数据会被视为另一个 App 的数据（不会互通）。

## 设置「识图记账」快捷指令

App 内 设置 › 快捷指令 › 识图记账设置教程 里也有同样的步骤。

**方案一：轻点背面 / 操作按钮，一键截屏记账（推荐）**
1. 打开「快捷指令」App → 右上角 ＋ 新建。
2. 添加操作 **截屏**。
3. 添加操作 **识图记账**（搜索「简账」），「图片」参数会自动连接上一步的截屏。
4. 「审核方式」默认 **弹窗审核**（见下）；想一键记账改为「直接保存」。也可以固定一个分类或账户。旧版快捷指令里的「保存前确认」仍然有效，现在等同于弹窗审核。
5. 命名为「识图记账」。
6. 设置 › 辅助功能 › 触控 › **轻点背面** → 轻点两下 → 选择该快捷指令；iPhone 15 Pro 及以上也可在 设置 › **操作按钮** → 快捷指令 中绑定。

之后停在支付宝 / 微信的支付成功页，轻点两下手机背面即可自动记账，顶部会弹出「已记账：支出 ¥35.00 · 餐饮 · 星巴克 · 10月18日 12:30」。

**弹窗审核（不打开 App）**

识别后在快捷指令弹窗中列出每一笔（序号、收支、金额、分类图标、商户、账户、时间；已有相同记录的标为「已存在 · 跳过」），然后选择：

- ✅ **全部保存（N 笔）** — 保存并显示结果卡片；
- ✏️ **修改第 X 笔** — 选择要改的项目：金额 / 收支类型 / 分类 / 商户·备注（输入「星巴克 / 下午茶」，「-」清空）/ 账户 / 时间，改完选「完成」回到列表；
- 🗑 **删除第 X 笔**；➕ **添加一笔**（金额 → 类型 → 分类 → 商户·备注可跳过 → 账户可选自动）；
- ♻️ 重复项改为 **仍然保存** / 改回跳过；**取消**（不保存任何记录）。

只有一笔时不再询问「第几笔」。修改过分类或账户的商户会更新「分类记忆」；保存后检查预算并发送预算提醒，结果对话框里附带本月预算剩余。为防止死循环，一次最多询问 30 步，超过后会请你确认保存当前结果。

不同系统版本的交互：
- **iOS 26**：`requestChoice(between:dialog:view:)` —— 按钮 + 识别结果卡片（SwiftUI 片段视图），选项超过 8 个时（如账户很多）改用列表；
- **iOS 17 / 18**：没有多选按钮接口，改用参数的 `requestDisambiguation(among:dialog:)` 弹出选择列表（每项带图标和副标题），识别明细写在提示文字里；最后的「已记账」结果卡片在所有版本都显示。
- 弹窗内**只保留按钮操作**（类型 / 分类 / 账户 / 时间改为现在 / 删除 / 重复项）。金额、商户、备注、自定义时间、添加一笔等需要打字的操作会**先保存当前列表，再打开简账**进入编辑页或新建页（`jianzhang://pending-edit`）。若 App 有密码锁，解锁后（面容 ID 或真实密码）再弹出编辑页；若用防窥密码解锁，会忽略这次跳转，以免露出真实记录。
- iOS 27 上 `requestChoice` 之后再调任何 `requestValue`（含 String）都会直接关弹窗，因此放弃弹窗内输入。

截图 `22-review-snippet.png` 是在 App 里渲染的弹窗示意（快捷指令的真实弹窗无法在 CI 中截图）。

**方案二：从相册选择**：「选择照片」→「识图记账」。

**方案三：共享表单**：在快捷指令详情里打开「在共享表单中显示」，接收「图像」，下一步「识图记账」，就能在相册里分享截图来记账。

识别不准时，可以在首页点开这条记录修改。

## 隐私说明

- **默认所有数据只保存在本机**（SwiftData 本地数据库），不包含任何自有服务器或网络请求代码，不接入任何统计 / 广告 SDK。
- **OCR 在设备上完成**（Apple Vision 框架），截图不会离开手机，App 也不会保存截图本身。
- 密码只以加盐哈希形式存于钥匙串，且仅本设备可用。
- 只申请面容 ID 权限（用于解锁）；相册通过系统照片选择器按需选图，不读取整个相册。通知权限只在打开周期账单提醒或预算提醒时申请，通知全部为本地通知。
- 导入的账单文件只在本机解析，不会保存原文件。
- **注意**：快捷指令 / Siri 的「识图记账」「记一笔」「本月收支」在后台运行、不显示界面，因此 **不需要输入 App 密码**；但它们都设置了 `authenticationPolicy = .requiresAuthentication`，需要 iPhone 本身已解锁才能运行。如果在意「本月收支」被他人通过 Siri 听到，可以在「快捷指令」App 中关闭该 App 的 Siri 建议。
- 数据备份：在 设置 › iCloud 与备份 中导出加密备份（.jzbackup，可完整恢复，忘记密码无法恢复）或开启自动备份；CSV 导出用于表格分析（明文）。卸载 App 会删除本机数据（iCloud 云盘中的备份文件不受影响）。
- 网络：只有在你使用付费账号签名并主动开启「iCloud 同步」时，数据才会经由 Apple 的 CloudKit 同步到你自己的 iCloud 私有数据库；简账本身没有任何服务器。
